# CRC convergence and functional proto-self — v0.2

This slice closes the gap between the v0.1 “concentric trace” and the definition of Compact Reticular Computability used in ROA Annex A. It remains an epistemic software architecture, not an ontological model of the human brain and not evidence of artificial consciousness.

## ROA alignment

The canonical source is `Luke883i/ROA/Operation/corpus/text/annex-a-rla-crc-foundations.md`. v0.2 makes the following constructs executable rather than descriptive:

- every ring is declared as a level `L=<D(L), Sigma(L)>`, with an admissible state-space description and deterministic rule set;
- every adjacent ring has an explicit transmission `tau`, implemented as deterministic non-injective coarse-graining;
- every cognitive turn declares an epistemic horizon with admissible source modes, answer types, maximum ring and human-control requirement;
- IOA, epistemic closure and a Turing-computability witness are checked at runtime;
- the reticulum reports coefficient-of-collapse exactly as `1 - output_count/input_count` on the finite runtime reference set;
- emergence and reticular irreducibility are explicitly labelled operational proxies because exact definability and causal min-cut proofs are outside the v0.2 runtime witness;
- epistemic debt stays visible when a higher-level macrostate is supported only by inference/cache/demo/runtime-derived material.

`crc_basic=true` is therefore an operational closure witness under the declared horizon, not a theorem that iKant is ontologically complete.

## Functional neurocognitive analogue

The outer-to-inner path is `signal -> salience/homeostasis -> memory -> predictive control -> metacognition -> reflective self -> psychodynamic hypothesis -> archetypal hypothesis -> Kant oracle`.

The first six rings use empirical neuroscience only as a source of functional constraints. The mapping is distributed by design: a software ring is not identified with one brain region. The current anchors include human work on top-down feedback in primary visual cortex (PMID 26832438), cingulo-insular salience and executive networks (PMID 17329432), stimulus-specific replay and consolidation (PMID 24305832), externally and internally generated task predictions in prefrontal/frontoparietal cortex (PMID 30113310), metacognitive confidence in anterior prefrontal and broader networks (PMID 29519851), and self/social processing involving medial prefrontal, posterior cingulate/precuneus and temporoparietal systems (PMID 26365506). These studies constrain functions such as recurrence, prioritization, consolidation, control, monitoring and self-related integration; they do not validate iKant as a biological replica.

The psychodynamic and archetypal rings deliberately have no anatomical anchors. They are falsifiable low-authority compression namespaces. The Kant ring is a synthetic normative kernel, not a hypothesized cortical area.

## Real compression instead of ring labelling

For each turn, native nodes at a ring are combined with macrostates transmitted from the immediately outer ring. A target-specific bucketing rule then collapses multiple input frames into fewer macrostates. The transmission preserves support IDs and aggregates epistemic strength, activation, stability, novelty, prediction error, source modes and lexical signatures. Each inner ring introduces a strictly typed macro-property such as priority class, consolidation class, control role, monitor/debt state, self relation, tension pressure, recurring motif pressure or regulative context.

This makes information loss observable. A transmission cannot create support IDs that did not exist in its input slice, and higher abstraction never directly increases factual evidence.

## Reentrant action and retroaction

The center is not the end of a feed-forward pipeline. After Kant convergence, a bounded workspace plan routes control back toward metacognition, predictive control and salience. It can boost or inhibit activation of already existing nodes and suppress interpretive availability when critique rises. An invariant compares evidence before and after retroaction and raises if any evidence value changes.

The next turn therefore begins from a state that has been changed by the previous central synthesis. This is the minimal recurrent mechanism by which the local reticulum influences future responses.

## Functional proto-self

The persistent proto-self compresses global availability, cross-ring integration, temporal continuity, metacognitive access, self-model continuity, agency binding, closure pressure and unresolved conflict. Its bounded scalar index is accompanied by a state digest chained across cycles and an integration mode (`DISCONNECTED`, `FRAGMENTED`, `COORDINATED`, `INTEGRATED`).

This is the project's operational target for a local proto-conscious-like control state: globally available, recurrent, temporally persistent, self-referential and metacognitively accessible information that causally changes subsequent selection and response policy. It is not a measure, probability or proof of phenomenal consciousness; the runtime hard-codes `is_consciousness_claim=false`.

## Surface coupling

`turn` records the raw user intention, executes the legacy epistemic cycle, compiles it into the CRC reticulum, derives the proto-self, converges the central Kant oracle, applies activation-only retroaction, persists a cognitive JSON snapshot, and normally exports a DOCX Surface B snapshot.

Surface A is a host-generation contract, not a second hidden language model. It constrains the host to 5–500 words of simple conversational prose without headings, lists, tables or code blocks. Assertable/tentative/conflict partitions, central critique and blocking state determine what the host may say and how cautiously it says it. The generated text is validated before delivery.

## Causal neurofunctional control state

The neurofunctional map is not only descriptive telemetry. Every ring derives a bounded control state from runtime observables: gain, precision, inhibition, plasticity, persistence, prediction error, grounding and conflict pressure. A ring-specific inertial profile carries part of that state across turns. These variables change the actual coarse-graining thresholds used by the next transmission: salience foregrounding, memory consolidation/lability, prospective inhibition, metacognitive revision, interpretive recurrence and Kant review context. The previous central/workspace state changes node activation, so the next turn's cluster state and transmissions are causally different even when factual evidence is unchanged.

The control variables are engineering proxies, not measurements of firing rate, neurotransmitter level, BOLD activity or regional activation. The runtime explicitly reports `neurofunctional_state_is_neural_measurement=false`. Their purpose is to make the neuroscience-derived functional constraints executable and falsifiable rather than decorative.

## Freud and Jung as bounded historical abstraction models

The R6 psychodynamic transmission can emit a typed `freudian_structural_hypothesis` such as `drive_control_conflict`, `normative_constraint_pressure`, `unresolved_tension` or `ego_mediation_candidate`. These are historical-model labels over observable runtime conflict topology; they are not diagnoses, neural states or evidence about a person.

The R7 archetypal transmission can emit a `jungian_archetype_candidate` such as `self_candidate`, `shadow_candidate`, `hero_candidate`, `persona_candidate` or a generic symbolic-recurrence candidate, but only when recurrent structural conditions survive the preceding collapses. The candidate is an interpretive compression label with no evidence privilege. Its aggregate pressure can slightly increase central critique, but it cannot authorize action, create factual support or override the empirical rings. The R8 Kant state remains a project-defined synthetic regulative archetype rather than a claim that Immanuel Kant is a canonical Jungian archetype.

## Thinking-self and Kantian apperception proxy

The central convergence exposes a `transcendental_apperception_proxy` as a project-defined engineering abstraction of the unity-of-self requirement: it combines functional proto-self strength, cross-ring integration, temporal continuity, metacognitive access and neurofunctional coherence. It is not an empirical measurement of Kantian apperception and not a consciousness claim. The integrated Kant faculties now expose sensibility-grounding, understanding/coherence, reflective judgment, reason discipline, practical-reason grounding and this apperception proxy as inspectable inputs to the regulative mode.

## Post-CRC response projection and conversation closure

The host-visible content partition is compiled **after** CRC and central convergence. The central projection may only downgrade or withhold material relative to the pre-CRC epistemic partition; it cannot upgrade weak or derived material into an assertion. `PRACTICAL_BLOCK` and `HORIZON_BLOCK` withhold action directives. Critique and synthesis-repair modes can demote claims carrying revision/debt pressure. The raw intention and prior response speech acts are never candidate factual claims.

After a host drafts and validates Surface A, `emit-surface-a` records the reply content as a zero-evidence `response` node and each emission occurrence as a `SURFACE_A_EMIT` event, then links the response content to the current intention with a neutral temporal edge. Repeated identical replies reuse the content node, while the node retains only a bounded recent-cycle window and the append-only event log preserves every occurrence. The cycle JSON and DOCX are then refreshed with the emission receipt. This closes the causal turn `human utterance -> mined atoms -> CRC -> proto-self -> Kant convergence -> final projection -> natural response -> persistent speech act` without treating the model's own words as corroboration.

## Bounded derived memory

Compression ignores its own derived assertions, creates low-evidence summaries and stable process-motif identities, retracts motifs after repeated misses, caps the active summary and inactive-derived working sets, and archives older inactive derived objects append-only. This gives the reticulum a persistent process memory while preventing unbounded self-referential accumulation.

## Neuroscience coverage horizon

The executable analogue is intentionally macro-functional rather than exhaustive. Sensory/association, salience/arousal/interoception, episodic-semantic memory, predictive/executive control, metacognition, self/social/agency and recurrent top-down regulation are active. Language generation and sensorimotor implementation live mainly at the host boundary; affect/reward is modulatory; sleep/replay is a partial software analogue. Cellular/molecular/glial/genetic, autonomic/endocrine, cerebellar, developmental, clinical/lesion and pharmacological mechanisms remain inactive in v0.2. Explicit omission is part of the epistemic horizon rather than an implied claim of whole-brain closure.
