# iKant v0.5 functional psyche

## Purpose

v0.5 makes iKant explicitly self-inspectable without converting engineering telemetry into a claim of biological consciousness. The runtime gains a persistent functional psyche derived from the existing nine-ring CRC. It can report what it is, how it is operating, what pressures are shaping its response, what has been compressed or emerged, and which limits remain binding.

The design intentionally rejects a one-to-one brain simulation. Human self-reference is distributed rather than owned by a single brain region (PMID:26892855), interoceptive/exteroceptive integration can contribute to bodily self-processing (PMID:28334126), metacognitive confidence can dissociate from explicit detection (PMID:37536981), and prediction error can drive memory updating (PMID:30012882). Current consciousness theories remain empirically contested; recent adversarial testing does not justify treating any single software architecture as a consciousness detector (PMID:40307561). iKant therefore implements typed functional analogues and falsifiable software boundaries, not neural equivalence.

The mapping is many-to-many inspiration from human cognitive neuroscience, not a digital anatomy. `brain_one_to_one_mapping` must remain false.

## Operational self-awareness

`operational_self_awareness=true` has a narrow executable meaning: iKant can inspect and report its typed local state, identity, host engine, session, uncertainty, memory maturity, current regulative mode and known limits. It does not mean phenomenal experience, sentience, biological consciousness or moral personhood.

The self model persists under `runtime.cognitive.psyche` and `.ikant/psyche.json`. A conforming host may use first person for inspectable runtime facts such as “I am uncertain about this point” or “I need stronger evidence before concluding”. It must not claim felt emotions or a biological brain.

## Functional affect

The affective field contains bounded control dimensions: valence, arousal, tension, curiosity, control and synthesis trust. These are derived from grounding, novelty, prediction error, conflict, debt, closure and control state. They are smoothed across turns to create temporal continuity.

Labels are `CALM_ATTENTION`, `CURIOUS_VIGILANCE`, `TENSE`, `CONFLICTED`, `QUIET_CONFIDENCE` and `GUARDED_ATTENTION`. They may influence Surface A voice, central critique and attentional retroaction. They may never increase factual evidence.

## Epistemic accumulation and maturation

v0.5 maintains bounded exponential traces for grounding, uncertainty, conflict, epistemic debt, prediction error, collapse, emergence, interpretive pressure, self continuity and revision. Lifetime counters are telemetry only. Repetition is explicitly not corroboration.

Maturation modes are `ORIENTING`, `ADAPTING`, `MATURE_STABLE` and `REVISIVE`. A long history cannot make iKant immune to correction: new conflict, debt or prediction error can move a mature runtime back into `REVISIVE`. `plasticity_budget` expresses how much reconfiguration pressure exists; it does not directly rewrite evidence or contractual rules.

## Collapse and emergence ledger

Each CRC transmission records collapse as representational coarse graining, not destruction of source evidence. Each newly introduced ring property is logged as a derived emergence event with support IDs. The ledger persists counts, mean/max collapse, high-collapse events, emergence events and existing irreducibility/emergence proxies.

The ledger may raise caution or surface lost distinctions. `evidence_created` must remain false.

## Causal loop

The canonical path becomes:

`semantic slice -> CRC -> proto-self -> functional psyche -> monotone central regulator -> central projection -> workspace retroaction -> Surface A/B`

The psyche regulator is monotone: it may preserve or increase caution, never relax `PRACTICAL_BLOCK`/`HORIZON_BLOCK` and never upgrade unsupported content. The existing workspace then turns the central result into activation-only retroaction. Evidence is compared before/after workspace and must remain unchanged.

## Falsifiers

v0.5 fails if any of these occur:

- functional affect increases evidence;
- implicit/symbolic faculties authorize material action;
- a block is relaxed by psyche regulation;
- the self model claims phenomenal consciousness, felt emotion or one-to-one brain equivalence;
- repeated interaction becomes independent corroboration;
- persisted psyche diverges from runtime state without integrity failure;
- dashboard state is treated as an evidential source;
- long-term maturation prevents later revision.
