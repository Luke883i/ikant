# PR2 Definition of Done — CRC central convergence v0.2

PR2 is releasable only when every item below is satisfied on one exact source fingerprint and the hosted GitHub Actions receipt is PASS.

## Semantic and CRC correctness

- Every R0–R8 ring has an explicit state space, rule set and neurofunctional role or an explicit non-neural interpretive/normative boundary.
- Eight adjacent inward transmissions are executable and many-to-one collapse is measured per transmission.
- The runtime declares an epistemic horizon and fails closed for unknown rings, unsupported sources, malformed numeric state, horizon violations and divergent duplicate identities.
- IOA, epistemic closure, a Turing-computability witness, representational path and CRC-basic are exposed separately. CRC-strong remains only a candidate witness when debt is absent.
- Higher abstraction never increases external evidence. Center-to-periphery retroaction may alter activation, selection, inhibition and review pressure only.
- Psychodynamic and archetypal transformations remain low-authority interpretive hypotheses with no anatomical localization claim.

## Functional proto-self and central oracle

- Proto-self integrates availability, cross-ring integration, temporal continuity, metacognitive access, self-model continuity, agency binding, functional coherence and reentrant capacity.
- Proto-self survives durable reopen and remains explicitly `is_consciousness_claim=false`.
- The central Kant oracle consumes CRC and proto-self state and can reach reflective synthesis, practical review/block, horizon block and repair/critique regimes under controlled scenarios.
- Material human-impact uncertainty blocks autonomous material action.

## Surface A and Surface B

- Surface A contract requires 5–500 words, simple natural prose, at most four paragraphs, no headings, lists, tables or code blocks, and language matching the user.
- Surface A content is post-CRC and post-oracle; central critique may downgrade claims but never upgrade unsupported content.
- Emitted Surface A is a persistent speech-act node with zero evidence and bounded temporal linking.
- Surface B is a valid DOCX plus JSON runtime snapshot containing ring states, neurofunctional clusters/control, transmissions, CRC diagnostics, proto-self, central mode, retroaction, Surface A contract/emission, backlog and recent persistent events.

## Validation metrics

- Unit/edge suite: 100% pass with `ResourceWarning` promoted to error.
- Static graph stress: 10,000 cases plus 1,000 no-novelty recurrences, PASS.
- Dynamic runtime stress: 10,000 mixed operations plus 1,000 no-novelty recurrences on diversified independent seeds; sampled mean activation ceiling fraction <= 0.50 and saturation share above 85% <= 0.05.
- CRC stress: 10,000 reticula per diversified independent seed; all eight transmissions valid; mean collapse in engineering envelope 0.12–0.72; RIR proxy 0.70–1.00.
- Cognitive stress: repeated conversational turns preserve external evidence, keep response evidence at zero, keep response-cycle windows bounded and maintain mean activation below 0.70 of ceilings.
- Surface A stress: 10,000 valid/invalid format cases per selected seed, 100% classification.
- Central edge scenarios cover horizon block, practical block, practical review, reflective synthesis and repair/critique behavior.
- Dynamics tuning is recomputed from a deterministic parameter grid; hard invariants pass and defaults remain within 2.5 fitness points of the best candidate.
- All isolated receipts carry the same source fingerprint and aggregate to `release_candidate=true`.
- Clean-room checkout repeats the unit suite, quick gate, smoke dialogue and integrity reopen.
- GitHub Actions on the PR emits `HOSTED_CI: PASS` for the exact PR merge SHA.

## Claim boundary

These are engineering validation criteria for a local cognitive control architecture. They are not neuroscientific validation, evidence of phenomenological consciousness, a brain emulation, a clinical model, or a reconstruction of Immanuel Kant's mind.
