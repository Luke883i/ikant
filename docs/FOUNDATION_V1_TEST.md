# iKant Foundation v1-test

Foundation v1-test is the first product slice that treats iKant as an end-user experimental environment instead of a collection of internal runtime surfaces.

## Public promise

The web application may show only a service that the current local runtime can demonstrate now. A visible service is a derivative capability projection, never permission, approval, execution authority, evidence or proof of world truth. Features that exist only as future supply contracts remain absent from the ordinary product UI.

The experimental configuration is local, revision-bound and bounded. Its meta prompt and selectable guardrails influence only generation formatting/discipline. They cannot enable model tools, create material authority, expose private chain-of-thought or relax the constitutional authority chain. Configurable guardrails are deliberately one-way: they can reduce reply length, make evidence handling stricter, surface/abstain on conflicts, or disable interpretive hypotheses.

## Runtime reconciliation

The canonical path is:

`pair/admission -> verified managed runtime -> exact single-writer shell -> cognitive compile -> generation contract + experiment config -> validated reply -> exact frame ACK -> response memory(evidence=0) -> same-cycle epistemic snapshot -> optional post-ACK DOCX -> Foundation projection`.

The Foundation projection reconciles four user-visible questions without inventing new runtime state:

1. What can iKant actually do in this state?
2. What generation preferences are active?
3. What evidence/derivation/conflict value is available for the current cognitive cycle?
4. Which artifacts are actually present now?

## Minimal UI

The existing chat remains the only primary semantic viewport. Foundation adds one on-demand environment panel under Details. It contains only runtime-backed service rows, a compact epistemic-value summary and an editable experiment configuration. Voice controls remain absent unless loopback STT or an explicitly local browser speech capability can be demonstrated. DOCX is absent until the same-cycle file exists after ACK.

## Falsification contract

S12 uses three deterministic harnesses. Stress covers multi-level state composition; mutations cover capability/config/evidence/authority failure families; edges cover reconciliation boundaries and compression minimality. The declared deep-current gate is 10,000,000 cases/mutations/edges with a 100,000 no-novelty tail. The edge harness also treats the 100,000 tail as a no-better-compression search: any candidate that removes one of the required Foundation faculties must lose at least one promise property.

These are semantic/runtime-contract simulations. They do not substitute for real browser, OS or external-provider execution tests.
