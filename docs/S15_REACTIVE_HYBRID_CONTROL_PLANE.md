# S15 — Reactive Hybrid Control Plane

## Ontological target

iKant moves toward a **Local Cognitive Runtime**: local governance remains the only authority path; common commands can be compiled without LLM inference; expensive language work is represented by a bounded semantic work graph; optional commercial models may contribute only abstract, zero-authority findings through a deterministic membrane.

The human product is compressed into two visible layers: the existing final sealed Surface A and a transient, authenticated cognitive-moment projection (`INTAKE → ROUTING → BACKEND_WORK → DELIVERY`). The projection is not conversation history, evidence, authorization, consciousness, percentage progress, or chain-of-thought.

`floating` in S15 means a compact PWA/web presentation mode. It does not claim an always-on-top native OS overlay and creates no new execution authority.

## Deterministic essential commands

`Apri Firefox`, `Apri Firefox e Word`, `Open Chrome and Excel` compile into bounded `OPEN_APP` plans. Only an allowlisted app vocabulary is accepted; paths, URLs, flags, shell syntax, unknown apps, and more than four targets fail closed. The plan requires `native.app.open`, an S1 lease and fresh host revalidation, and itself has zero execution authority.

S14 native actions explicitly forbid process execution, so S15 compiles but does **not** launch applications yet. A later native-host slice must attest installed application identity and implement `native.app.open` without shell interpolation.

## Hybrid commercial membrane

Commercial assist is optional and never a governance path. OpenAI, Anthropic and DeepSeek transports are pinned to their official API surfaces; credentials remain local; only already-minimized abstract capsules are accepted. Secrets, local paths and emails are rejected again at the transport boundary. Tools are forbidden. Provider output has evidence/epistemic/execution authority `0.0`; timeout, malformed output or tool-bearing output returns `local_fallback_required`.

Remote routing requires explicit opt-in, an allowed provider, abstract operations only, and every sibling unit to be exportable and non-material. One private or material unit quarantines the whole turn locally. The canonical TURN does not automatically invoke a commercial provider in S15; activation remains a separate user/configuration gate.

## Runtime path

`TURN → reactive control record → canonical AdvancedWebShell TURN → sealed frame → exact ACK`

The reactive HTTP wrapper never calls `service.turn()` directly. It delegates `service.shell_command()` and `service.shell_ack()` to the existing single writer. A retry while work is active is not intercepted as a new job: the canonical shell remains responsible for replay/conflict semantics. The work record becomes terminal only after the existing exact ACK succeeds.

## Global DoD

- exact ACK and single-writer semantics unchanged;
- no second semantic human-output channel;
- work projection authenticated, identifier-minimized, bounded and zero-authority;
- no fake progress percentage or raw reasoning;
- stale/overlapping progress polling cannot resurrect a finished balloon;
- deterministic command compilation performs no execution and creates no shell string;
- private/material mixed turns are wholly quarantined from commercial routing;
- provider tools are rejected and provider failure cannot make the local runtime unavailable;
- web and compact floating presentation consume the same semantic moment contract;
- real Chromium liveness is required before merge to prove polling remains live during a slow synchronous TURN;
- native app launch is not claimed until a separately governed host capability exists.

## Local and intermediate gates

**S15-A Reactive UX:** live authenticated polling; `INTAKE/ROUTING/BACKEND_WORK/DELIVERY`; details on demand; terminal after ACK.

**S15-B Command compiler:** known `OPEN_APP` commands compile without LLM inference; malformed or unknown requests fall back; max four targets; zero execution authority.

**S15-C Hybrid membrane:** explicit opt-in; whole-turn quarantine; provider host pinning; no raw local context; tools rejected; local fallback on failure.

**S15-D Bounded runtime:** max 24 semantic units, 48 edges, 64 retained work records with active-state fail-closed behavior.

## Evidence boundary

The pre-PR laboratory executed five independent seed-model campaigns of 10,000,000 mutations each (50,000,000 total), 40 mutation families, plus 87,501 actual candidate-code fuzz cases; final survivor count was zero. Control-plane benchmarks measured ~0.004 ms p50 for command translation, ~0.026 ms for a command graph, ~0.052 ms for an abstract graph and ~0.076 ms for reactive begin. These measurements do **not** claim real Qwen TTFT/semantic equivalence, live provider success, native app launch, or native always-on-top floating behavior.
