# iKant v0.2

iKant is a repository-local cognitive runtime for conforming AI assistants. It turns a human intention into persistent epistemic objects, a ROA-aligned Compact Reticular Computability (CRC) witness, progressively compressed macrostates, a persistent functional proto-self and a central Kant-inspired regulative state that changes what the host can assert, foreground or act on.

The architecture is deliberately bounded. It is not a brain simulation, diagnostic instrument, moral agent or proof of artificial consciousness. Neuroscience supplies falsifiable functional constraints; Freud/Jung vocabularies remain low-authority interpretive hypotheses; the Kant center is a synthetic normative kernel.

## Admission and local start

Requires Python 3.11+ and a writable checkout. Installation is not required.

```bash
python -m ikant gate
python -m ikant accept "I ACCEPT"
python -m ikant probe
python -m ikant initialize
python -m ikant integrity
```

A public-repository host can begin from `inizializza iKant https://github.com/Luke883i/ikant`. Discovery is not acceptance. Exact human `I ACCEPT`, a real probe and a fresh single-use probe receipt remain mandatory.

## Canonical cognitive turn

After ACTIVE, `turn` is the v0.2 entrypoint:

```bash
python -m ikant turn --intent "your current intention" --atoms-json atoms.json
```

The command records the raw intention as an attributable speech-act object, ingests explicitly mined atoms with provenance bounds, runs the persistent epistemic cycle, performs eight explicit CRC transmissions, derives a functional proto-self, converges the Kant center, compiles a post-CRC response projection, applies bounded center-to-periphery activation retroaction, persists a JSON cognitive snapshot and exports a DOCX Surface B snapshot under `.ikant/artifacts/`.

`cycle` remains available as a lower-level v0.1 diagnostic.

## Two runtime surfaces

Surface A is the conversational answer emitted by the AI host. The runtime supplies a hard contract: 5–500 words, simple natural prose in the user's language, no headings, lists, tables or code blocks, and content/certainty constrained by the current CRC, proto-self and central oracle. A conforming host validates its draft with:

```bash
python -m ikant validate-surface-a --text "candidate reply"
python -m ikant emit-surface-a --cycle-id <cycle> --intention-node-id <node> --text "candidate reply"
```

Surface B is the auditable per-turn DOCX/JSON photograph of the local reticulum. It contains the functional neurocognitive map, CRC levels/transmissions, ring macrostates, collapse/emergence/irreducibility proxies, epistemic debt, proto-self, central oracle, recurrent workspace effects, Surface A contract and recent persistent events. It is external engineering telemetry, not private chain-of-thought.

## ROA-aligned CRC

v0.2 implements each concentric ring as an explicit state/rule level and each outer-to-inner step as a deterministic non-injective transmission. The runtime declares an epistemic horizon and checks IOA, epistemic closure, a computability witness and representational path completeness. It reports coefficient-of-collapse and explicitly labelled emergence/irreducibility proxies. See `docs/CRC_CONVERGENCE_V02.md`.

## Neurofunctional analogue

The functional path uses sensory/association processing, cingulo-insular salience/homeostasis, hippocampal/medial-temporal memory, prefrontal/frontoparietal predictive control, metacognitive monitoring and medial self/social integration as engineering anchors. These are distributed functional analogies, not one-to-one cortical modules. Higher psychodynamic/archetypal layers have no anatomical claim.

The neurofunctional map is executable rather than decorative: bounded cluster-control state changes CRC transmission thresholds and persists across cognitive turns, while remaining explicitly labelled as a software proxy rather than measured brain activity.

## Persistent derived memory and dialogue closure

Runtime compression is bounded and non-self-evidentiary. Active summaries and inactive derived objects have working-set limits; stale derived nodes can move to an append-only archive. Process motifs may influence retrieval and critique but never become external proof. Surface A emission is persisted as a zero-evidence response speech act, linked to the user turn, and the same Surface B JSON/DOCX is refreshed so the exported snapshot covers the complete input-to-output iteration.

## Neuroscience coverage boundary

The active functional analogue covers the macro-systems needed by the CRC path; it does not claim whole-brain biological equivalence. Language generation and sensorimotor execution remain host-bound, affect/reward is modulatory, sleep/replay is only partially analogous, and cellular, endocrine, cerebellar, developmental, clinical and pharmacological mechanisms are explicitly outside the active v0.2 horizon.

## Validation

The repository retains the v0.1 recurrence/corroboration, retraction, feedback, persistence, tamper and dynamic stress gates. v0.2 adds real parameter-grid tuning, runtime-sized CRC stress, Surface A format fuzzing, recurrent cognitive stress, durable Surface B snapshot tests and hosted CI matrices. Validation scores are engineering diagnostics, not neuroscientific fit or consciousness evidence.
