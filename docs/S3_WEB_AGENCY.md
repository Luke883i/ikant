# S3 Web Agency

S3 adds a minimal isolated-web sensor/actuator boundary on top of merged S1 Agency Kernel and S2 Local Embodiment. It does not create a new authorization path.

## Semantic chain

`WebSnapshot -> WebAction -> S1 HumanFrame/Grant -> S1 ExecutionLease -> v0.18 host revalidation -> browser commit -> v0.17 execution receipt`

Every arrow is conjunctive. Web content, a model proposal, a browser capability or a successful host-conformance probe never implies authority to perform the next step.

## WebSnapshot

A snapshot is a bounded observation from one browser/page/navigation epoch. Page text and control labels are always tagged `UNTRUSTED_WEB_CONTENT`. Cookies, storage and secrets are excluded. The snapshot has epistemic authority `0.0` and execution authority `0.0`.

Controls receive deterministic opaque IDs generated by iKant from bounded current-page properties. Model/user proposals never supply arbitrary CSS/XPath selectors or JavaScript. A stale snapshot, changed navigation epoch, changed URL/origin or missing/ambiguous target fails closed.

## WebAction

S3 supports only `NAVIGATE`, `CLICK` and `FILL`.

- `NAVIGATE` requires `web.navigate` over one exact canonical URL.
- `CLICK` requires `web.click` over the exact origin + snapshot digest + generated control ID.
- `FILL` additionally binds the SHA-256 digest of the exact input value.

Every capability/resource is passed through the S1 canonical entitlement validators. Wildcards, URL userinfo, non-http(s) network schemes, control characters and path traversal segments fail closed.

## Browser commit point

The actuator sequence is:

`snapshot recheck -> browser preflight -> v0.18 host revalidation -> snapshot recheck -> consume one-shot S1 lease -> external browser commit`

The S1 lease is consumed immediately before the external side effect. If the browser operation fails after that point, S3 records a FAILED execution receipt; it does not silently retry with the same lease. A retry therefore requires fresh authority.

The optional Playwright adapter starts at `about:blank` and performs no network navigation during construction. The first network request must itself be an authorized `NAVIGATE`. Popup/new top-level navigation is blocked. Explicit `NAVIGATE` also blocks redirects to any URL other than the exact authorized URL. A click that attempts an unleased cross-origin navigation is aborted and reported failed.

## Host and authority boundary

`WebExecutionHostAdapter` participates only in the existing v0.18 `EXECUTION_HANDOFF` profile. It has no HUMAN_EGRESS or MACHINE_OUTPUT privilege and does not execute actions during revalidation. S1 remains the sole grant/lease authority kernel.

A web-action grant uses an ordinary S1 `CAPABILITY_GRANT` HumanFrame with `max_uses=1` and the exact web entitlement. Page content cannot issue, extend, revoke or approve that grant.

Execution receipts are v0.17 control observations. They do not establish world truth, factual evidence or actor authentication.

## Validation

Final local candidate:

- targeted S3 tests: 17/17 pure runtime tests PASS before repository integration; repository integration tests additionally exercise the real S1 grant/lease and v0.18 revalidation path;
- semantic stress: 100,000 cases + 10,000 no-novelty tail; all 65,536 explicit configurations covered; 6 consequence signatures; 0 violations; 0 tail novelty;
- edge saturation: 100,000 cases + 10,000 tail; all 32,768 explicit configurations covered; 288 signatures; 0 violations; 0 tail novelty;
- semantic mutation campaign: 100,000 mutations + 10,000 tail; 80/80 families covered; 0 survivors; 0 tail-new families.

These campaigns are executable semantic/adversarial models, not a claim of formal verification.

## Deferred by design

S3 does not add an attached-human-browser extension, native OS access, autonomous scheduler, arbitrary JavaScript, cookies/storage export, password-manager access, browser downloads, silent retries or background network acquisition. Those later surfaces must preserve the same S1 lease and exact-resource boundaries.
