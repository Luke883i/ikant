## Core invariants

Admission remains exact-human `I ACCEPT`, followed by a real single-use probe. ACTIVE state is not reached until the immutable Kant kernel is seeded. Durable runtime remains single-writer and fails closed on admission, event-log, relation-endpoint, response-speech-act, proto-self-boundary or bounded neurofunctional-state tampering.

Recurrence changes familiarity/availability but not evidence. Corroboration requires provenance-distinct attributable evidence. Retraction cannot be undone by recurrence. Derived/inferred goals cannot silently become authorized directives. Modulators, compression, proto-self integration and center-to-periphery retroaction may change activation, retrieval, caution or inhibition but never manufacture external evidence.

The v0.2 CRC compiler additionally fails closed for unknown rings, unsupported sources, source modes outside the declared horizon, malformed/non-finite numeric state and divergent duplicate identities. Every valid turn exposes eight adjacent transmissions and bounded collapse, emergence and irreducibility diagnostics.

Surface A emission is a zero-evidence persistent speech act. Repeated identical replies reuse content identity but retain only a bounded recent-cycle window while the append-only event log preserves every emission. The validator rejects Markdown/Unicode/HTML list forms, Markdown/setext headings, tables and code blocks in addition to word-count and sentence-length violations.

## Full isolated validation

A full release witness is generated by running the documented profiles independently and saving their JSON outputs into one directory. Then run:

```bash
python scripts/aggregate_validation.py --dir <receipt-directory> --output full-validation.json
python scripts/release_gate.py --receipts-dir <receipt-directory>
```

The aggregator rejects missing receipts, stale source fingerprints, wrong scales/seeds, saturation breaches, CRC envelope breaches, dialogue failures or any central/edge profile that does not satisfy its declared invariants.

The required core full seeds are `1, 17, 97, 883, 2026` for dynamic and CRC 10k profiles; cognitive seeds are `17, 883, 2026`; central and edge seeds are `1, 97, 883`; Surface A seeds are `1, 883`.
