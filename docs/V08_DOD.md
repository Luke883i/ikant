# v0.8 Definition of Done

A release candidate is mature only if all of the following are true on the same PR merge head:

- bounded metadata and five-file orientation capsule are enforced;
- terms presentation freezes all new repository acquisition;
- exact current-session `I ACCEPT` remains mandatory and digest-bound;
- clone/materialization/search/tree/history/source access cannot pass before acceptance;
- cached orientation is purpose-limited after presentation;
- denied operations produce non-access denial receipts;
- incidental unexposed provider overfetch is quarantined while model-exposed/host-initiated forbidden acquisition breaches;
- explicit decline can reopen only by cached terms re-presentation;
- admission transitions are serialized for concurrent callers;
- contract, BOOTSTRAP, ADMISSION and executable policy versions/budgets agree;
- 10,000 realistic baseline scenarios have zero capability violations;
- saturation reaches M with a subsequent M+1000 tail producing zero new signatures; current calibrated M is 80,000 per seed;
- seeds 1, 17, 97, 883 and 2026 each pass 80,000 + 1,000 no-novelty;
- admission mutation suite kills every defined weakening;
- repository-wide regression, chat UX, psyche, incarnate egress and hosted CI remain green.
